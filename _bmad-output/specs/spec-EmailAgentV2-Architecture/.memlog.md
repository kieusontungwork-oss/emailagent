updated: 2026-07-04T09:18

- (direction) Extracted spec from ARCHITECTURE-SPINE.md
- (decision) System is an Event-Driven, Modular Orchestration Pipeline using n8n
- (capability) CAP-1: System ingests incoming email events via Gmail trigger and delegates units of work
- (capability) CAP-2: System extracts text and scanned PDF data using local Vision LLM (Llama-3.2-Vision)
- (capability) CAP-3: System queries Postgres using strict parameterized SELECTs to fetch domain data
- (capability) CAP-4: System routes all errors to a universal Mailroom Error-Handler sub-workflow
- (capability) CAP-5: System tracks workflow state and idempotency checks in Postgres
- (constraint) n8n must operate as a stateless orchestrator
- (constraint) Pipeline split into Controller and independent Sub-workflows
- (constraint) n8n workflow JSON definitions must be managed as Infrastructure as Code via Git CI/CD
- (constraint) All LLM inference must occur on a local Vision LLM in air-gapped subnet
- (constraint) DB user must have strictly read-only permissions on domain tables
- (constraint) Secrets must be injected at runtime via HashiCorp Vault
- (event) Spec coherence and preservation validated
